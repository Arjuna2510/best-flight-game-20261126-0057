EMBERWING: Ridge Run — a pseudo-3D chase-view flight game in pure Canvas 2D, no network. Three missions: Dawn Patrol (12-ring run), Canyon Rush (16 rings + storm clouds), Relief Drop (3 crate drops + runway landing). Throttle, fuel and hull systems, WebAudio synth, keyboard + mouse controls. All three missions are winnable by autopilot sim.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 to play. The grader entrypoint is `node main.ts`, which copies `game/` and `screenshots/` to `/output` and writes `/output/dossier.json`.
